# Security policy

## Reporting a problem
Please report security problems **privately**, not in a public issue. On GitHub, open this repository's **Security** tab and choose
**Report a vulnerability**. Say what you found, how to reproduce it, and which app and version (Windows, Linux or Android).

This is a one-person, spare-time project, so there is no fixed response time.

## What counts
- A web page or server getting more access to the app than the bridge allow-list gives it (files, the operating system, other servers' data).
- Accepting a server's certificate or an update it should not.
- Saved sign-ins or keys readable by anything but the app.
- Installing an installer or APK that was not built and signed by the maintainer.
- Secrets in the repository or its history.

## Supported versions
Only the latest release receives fixes.
